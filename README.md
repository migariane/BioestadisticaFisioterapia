# Bioestadística para Fisioterapia

Diapositivas del curso de Bioestadística del Grado en Fisioterapia de la Universidad de Granada.

**Autor:** Miguel Angel Luque-Fernández  
**URL:** https://migariane.github.io/BioestadisticaFisioterapia/

## Estructura

- `*.qmd` — Archivos fuente Quarto (RevealJS)
- `_quarto.yml` — Configuración del proyecto
- `madrid-theme.scss` — Tema personalizado
- `data/` — Datos de ejemplo
- `logo.png` — Logo UGR

## Renderizado

```bash
quarto render
```

Los archivos renderizados se publican en la rama `gh-pages`.
